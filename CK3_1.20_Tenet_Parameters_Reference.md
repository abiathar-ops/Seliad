# CK3 1.20 "Crozier" — Complete Tenet Parameters Reference

**97 tenets** across Core (72) and PAM/By God Alone (25) have `parameters` and/or `personal_tenet_parameters` blocks.

> **Key distinction:**
> - `parameters` = Faith-wide boolean flags. Checked with `has_doctrine_parameter` (or `rite_has_parameter` in 1.20 rites).
> - `personal_tenet_parameters` = Flags only for playable characters who pick this as a personal tenet. Checked with `has_personal_tenet_flag`. Localized with `doctrine_parameter_` prefix.
